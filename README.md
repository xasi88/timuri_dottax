# Katar Café: меню с заказом в WhatsApp

Веб-приложение меню для Katar Café, Грозный, ул. Мира, 46 (Instagram @cafe_katar). Бета-версия.

Сайт: https://xasi88.github.io/timuri_dottax/ (коротко: https://clck.ru/3WXvyi)

- Тёмная тема в цветах логотипа, фото блюд из Instagram кафе.
- Нижняя панель как в приложении: Меню, Поиск, Заказ, Кафе.
- Фирменное блюдо на главной карточке, 5 разделов, 24 блюда, окно блюда.
- Заказ: в зале (номер стола), с собой, доставка. Уходит в WhatsApp готовым сообщением.
- На большом экране заказ стоит справа от меню.
- Можно добавить на главный экран телефона. Ссылка показывает картинку-превью в соцсетях.

Цены примерные. Блюда и цены правятся в `data/menu.js`.

Проверка: `node tests/logic.test.js`.
