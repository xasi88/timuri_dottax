# Katar: меню с заказом в WhatsApp

Демо электронного меню для кафе Katar, Грозный (Instagram @timuri_dottax).

- Первый экран: «Курица на углях», искры от углей, заказ в одно нажатие.
- 5 разделов, 25 блюд. Полоса разделов следит за прокруткой.
- Окно блюда, корзина, выбор: в зале (номер стола), заберу сам, доставка.
- Заказ уходит в WhatsApp готовым сообщением.

Цены примерные. Блюда и цены правятся в `data/menu.js`.
