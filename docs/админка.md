# Админка: как пользоваться

Адрес: https://xasi88.github.io/timuri_dottax/admin.html
На сайте ссылка внизу экрана «Кафе»: «Вход для владельца».

## Как это устроено

1. Админка меняет черновик. Черновик живёт только на этом телефоне.
2. «Просмотр» показывает сайт с черновиком. Гости черновик не видят.
3. «Опубликовать» отправляет меню на GitHub. Сайт обновляется через несколько минут.
4. Сайт и хранилище бесплатные (GitHub Pages).

Фото с телефона админка сама обрезает в квадрат 720×720 и сжимает.

## Подключить публикацию (один раз на телефон)

Нужен ключ доступа GitHub. Ключ даёт право менять только этот сайт.

1. Войти в GitHub под владельцем хранилища (сейчас xasi88).
2. Открыть https://github.com/settings/personal-access-tokens/new
3. Token name: «Админка Катар». Expiration: 1 год.
4. Repository access: Only select repositories → timuri_dottax.
5. Permissions → Repository permissions → Contents: Read and write.
6. Generate token. Скопировать ключ.
7. В админке вкладка «Доступ» → вставить ключ → «Подключить».

Ключ хранится только в браузере телефона. В коде сайта его нет. Чтобы закрыть доступ, удалить ключ на GitHub в том же разделе настроек.

## Если продаём меню владельцу

Лучше перенести хранилище на GitHub владельца (Settings → Transfer) или создать ему своё. Тогда ключ делает он сам, а адрес сайта станет `его-ник.github.io/timuri_dottax`.

## Что уточнить у владельца

- «Курица на углях»: в меню «от 400 до 1250». На сайте варианты «Порция» 400 ₽ и «Целая курица» 1250 ₽. Если есть «половина», добавить вариант.
- «Ког-корти 2300/2500»: на сайте «Средний» и «Большой». Узнать настоящие названия.
- Что такое «Баар-галнаш» и чай «Лев»: описания на сайте общие.
- Примеры акций и комбо (Семейное, Обед, скидка 10% от 3000 ₽, скидка 10% на мясо по-тайски) придуманы для показа. Владелец меняет или выключает их в админке.
