# timuri_dottax: меню кафе Katar

Демо электронного меню для кафе Katar (Грозный, ул. Мира, 46). Владелец Тимур, Instagram @timuri_dottax. Фирменное блюдо: курица на углях. Гость выбирает блюда, корзина считает сумму, заказ уходит в WhatsApp готовым сообщением.

Цель проекта: показать Тимуру демо и продать ему меню. Сведения о клиенте: `docs/клиент.md`.

## Правила проекта

- Сайт статический, без сборки: `index.html`, `styles.css`, `sheets.css`, `js/`. Блюда и цены только в `data/menu.js`.
- Телефон главный: гости приходят из Instagram с телефона.
- Длинное тире в текстах сайта не писать.
- Цены в `data/menu.js` примерные. Настоящие цены узнать у владельца.
- Фото блюд нет: вместо них рисунки в `js/icons.js`. Чужие фото с карт не брать. Фото дадут владельцы.
- Анимации уважают «уменьшить движение» (`prefers-reduced-motion`).
- Проверка интерфейса: ширины 375, 768, 1024, 1280, 1440. Искать текст за рамкой и горизонтальную прокрутку.
- Публикация сайта и сообщения владельцу: только после «да» пользователя.
- Репозиторий закрытый. Секретов в проекте нет.

## Как открыть

```bash
python -m http.server 5180
```

Потом открыть http://localhost:5180.
