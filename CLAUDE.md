# timuri_dottax: меню кафе Katar

Демо электронного меню для кафе Katar (Грозный, ул. Мира, 46). Владелец Тимур, Instagram @timuri_dottax. Фирменное блюдо: курица на углях. Гость выбирает блюда, корзина считает сумму, заказ уходит в WhatsApp готовым сообщением.

Цель проекта: показать Тимуру демо и продать ему меню. Сведения о клиенте: `docs/клиент.md`.

## Правила проекта

- Сайт статический, без сборки. Блюда и цены только в `data/menu.js`.
- Устройство: `index.html`; стили `css/base.css` (цвета, шапка, нижняя панель, кнопки), `css/menu.css` (экран меню), `css/views.css` (поиск, заказ, кафе, окно блюда); код `js/ui.js` (общие детали), `js/menu.js`, `js/order.js`, `js/app.js` (вкладки и запуск), `js/cart.js`, `js/icons.js`.
- Экраны: Меню, Поиск, Заказ, Кафе. На телефоне и планшете вкладки в нижней панели, на экране от 1024 вкладки в шапке, заказ стоит справа от меню.
- Превью для соцсетей: `img/og.png` (1200x630) и метатеги в `index.html`. Значки: `img/icon.svg`, `img/icon-*.png`, `manifest.webmanifest`.
- Телефон главный: гости приходят из Instagram с телефона.
- Длинное тире в текстах сайта не писать.
- Цены в `data/menu.js` примерные. Настоящие цены узнать у владельца.
- Фото блюд нет: вместо них рисунки в `js/icons.js`. Чужие фото с карт не брать. Фото дадут владельцы.
- Анимации уважают «уменьшить движение» (`prefers-reduced-motion`).
- Проверка перед коммитом: `node tests/logic.test.js` и проверка вёрстки `tests/layout.js` (функция `checkLayout()` в браузере) на всех экранах и ширинах 320, 375, 768, 1024, 1280, 1440.
- Имена классов не повторять между файлами: однажды класс `.empty` достался и кнопке, и пустому экрану, кнопка вылезла из рамки.
- Публикация сайта и сообщения владельцу: только после «да» пользователя.
- Репозиторий открытый (с 2026-10-16), сайт на GitHub Pages: https://xasi88.github.io/timuri_dottax/ . Push в main выкладывает сам. Секретов в проекте нет.

## Как открыть

```bash
python -m http.server 5180
```

Потом открыть http://localhost:5180.
