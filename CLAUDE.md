# timuri_dottax: меню кафе «Катар»

Электронное меню с админкой для кафе «Катар» (Грозный, ул. Мира, 46, «Куры на углях»). Владелец Тимур (личный Instagram @timuri_dottax). По визитке: Instagram кафе @kafe_katar, телефоны +7 (963) 980-28-78 (WhatsApp для заказов) и +7 (938) 890-29-70. Гость выбирает блюда и комбо, корзина считает сумму и скидки, заказ уходит в WhatsApp готовым сообщением. Владелец меняет меню и акции в `admin.html`.

Цель проекта: показать Тимуру демо и продать ему меню. Сведения о клиенте: `docs/клиент.md`.

## Правила проекта

- Сайт статический, без сборки. Блюда, цены, акции, комбо и данные кафе только в `data/menu.js` (внутри `window.KATAR` строгий JSON: его пишет админка).
- Блюда взяты с бумажного меню кафе (фото от 2026-10-16): 6 разделов, 35 блюд.
- Устройство: `index.html`; стили `css/base.css` (цвета, шапка, нижняя панель, кнопки), `css/menu.css` (экран меню, акции, комбо), `css/views.css` (поиск, заказ, кафе, окно блюда, установка); код `js/data.js` (данные, цены, черновик для ?preview), `js/ui.js` (общие детали), `js/menu.js`, `js/order.js`, `js/app.js` (вкладки и запуск), `js/cart.js`, `js/icons.js`, `js/install.js` (установка на телефон), `sw.js` (работа без сети).
- Админка: `admin.html`, `css/admin.css`, `js/admin.js` (экран), `js/admin-data.js` (файл меню, проверка), `js/admin-github.js` (коммит через GitHub API). Ключ GitHub хранится только в браузере владельца. Инструкция: `docs/админка.md`.
- Ключ корзины: `plov`, `chicken@1` (вариант блюда), `combo:family`.
- Экраны: Меню, Поиск, Заказ, Кафе. На телефоне и планшете вкладки в нижней панели, на экране от 1024 вкладки в шапке, заказ стоит справа от меню.
- Превью для соцсетей: `img/og.jpg` (1200x630, до 300 КБ для WhatsApp) и метатеги в `index.html`. Логотип `img/logo.webp` с визитки. Значки: `img/favicon.png`, `img/icon-*.png` (есть maskable), `manifest.webmanifest`.
- Телефон главный: гости приходят из Instagram с телефона.
- Длинное тире в текстах сайта не писать.
- Цены с бумажного меню. Примеры акций и комбо придуманы для показа: что уточнить, в `docs/админка.md`.
- Фото блюд в `img/food/`: часть из Instagram кафе, часть с Unsplash (с согласия пользователя), список в `docs/фото.md`. Блюдо без фото показывает рисунок из `js/icons.js`. Фото с карт и чужих страниц не брать. Фото из админки ложатся как `img/food/u-*.webp`.
- Цвета бренда по логотипу: угольно-чёрный, огненно-оранжевый, сталь. Тёмная тема.
- Анимации уважают «уменьшить движение» (`prefers-reduced-motion`).
- Проверка перед коммитом: `node tests/logic.test.js` и проверка вёрстки `tests/layout.js` (`await checkAll()` на сайте, `checkLayout()` в админке) на ширинах 320, 375, 768, 1024, 1280, 1440. Публикация админки: `tests/publish-check.html`, `await checkPublish()`.
- Встроенный браузер Claude не регистрирует service worker: офлайн проверять в Chrome.
- Имена классов не повторять между файлами: однажды класс `.empty` достался и кнопке, и пустому экрану, кнопка вылезла из рамки.
- Публикация сайта и сообщения владельцу: только после «да» пользователя.
- Репозиторий открытый (с 2026-10-16), сайт на GitHub Pages: https://xasi88.github.io/timuri_dottax/ . Push в main выкладывает сам. Короткая ссылка: https://clck.ru/3WXvyi (ведёт на сайт). Секретов в проекте нет.
